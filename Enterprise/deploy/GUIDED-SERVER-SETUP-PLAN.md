# Guided server setup reference plan (LAN-06 / M2)

A pure planning layer with explicit fresh and reconfigure intents and ordered prerequisite evidence: approved runtime/release, host inventory/lock, TLS/root trust, identity/database/migration/secrets, API/ingress, persistent admin/workspace/bootstrap closure, signed enrolled agent and independent field/recovery/release acceptance. Recompute from the beginning; do not trust a later stored or browser-supplied stage. Unknown or failed evidence blocks advancement, failed stage requires operator recovery rather than automatic replay. Existing state with missing identity/credentials blocks. Restore/clone is intentionally a different workflow. No secret values, database calls, network calls, authorization, persistence or installer actions in this planner. Even all claimed evidence cannot produce ACCEPTED or execution approval. These symbolic evidence states are caller inputs, not attestations. A production adapter must independently observe resources, authenticate evidence, bind it to installation and approved release, lock all mutations, enforce authorization and recheck on resume. Actual installer, durable progress, rollback, browser wizard integration and physical acceptance require DEC-001 and independent review.
