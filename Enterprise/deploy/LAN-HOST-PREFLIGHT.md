# LAN host read-only reference checks (LAN-02)

Reference Linux checks only. Caller supplies approved explicit minimum CPU, physical memory and target filesystem space, required TCP ports and paths of existing installation markers. Read-only local OS facts, statfs, lstat and bounded /proc/net/tcp and tcp6 inspection; no DNS, network transfers, socket binding, process invocation, credential reads, database access or file mutation. Missing markers do NOT prove absence of database/service/credentials. Missing/invalid observations are UNKNOWN; TCP listener snapshot is not a port reservation and can be stale. Current network namespace may not reflect the real host, especially inside containers. Thresholds are caller policy, not certified minimum requirements. Physical RAM may differ from cgroup limits; Linux/root observation is not supported-runtime or authorization proof. Windows host runtime and ACL adapter, host/service identity, actual DB inspection, offline dependency inventory, immutable staging and approved OS/runtime remain pending. Always reports installation_authorized=false. No installer or production integration; DEC-001 open.
