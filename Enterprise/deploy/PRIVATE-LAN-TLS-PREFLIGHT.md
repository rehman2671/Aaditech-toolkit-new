# Private LAN TLS reference probe (LAN-03 / AT-SEC-01)

Explicit opt-in TLS handshake to an operator-supplied RFC1918 or loopback IPv4 literal, with separately specified DNS name or matching private IP SAN. No resolver, proxy, HTTP, credentials, redirects, public-network fallback, trust-store changes or certificate download. Requires independently authenticated root certificate SHA-256 (DER), one self-signed CA, currently valid root, explicit CA-only TLS trust and standard certificate path validation. Requires TLS 1.2+, exact DNS SAN (no wildcard or CN-only fallback) or exact IP SAN, valid leaf and non-CA server certificate. Fixed deadline. All errors are generic and do not expose private hostnames or certificate contents.

Native Node/OpenSSL actual loopback handshake tests create disposable test CA and leaf certificates. Wrong signer/root, wrong hostname, wildcard and CN-only must fail. This is a live TLS-only reference check, not a fully offline host observation; it contacts only the explicitly approved private address. No production endpoint is probed in CI. Revocation, client/OS/browser trust installation, local PKI provisioning and key rotation, IPv6, private ingress/firewall, application readiness, certificate deployment, operator trust distribution and real enrolled Windows validation remain outstanding. Does not weaken public-DNS runtime policy. No install authorization or release acceptance.
