# Signed LAN bundle preflight (LAN-01 / AT-LAN-08)

This review-only extension builds on #102's hash-only LAN verifier. It adds the exported verifySignedLanBundle reference entry point. A detached raw Ed25519 signature authenticates the exact manifest bytes; the trusted public key, DER SPKI SHA-256 and exact approved manifest SHA-256 must be supplied independently from an authenticated release record. The supplied digest prevents a different previously signed manifest from replacing the approved release. The existing manifest/file and exact payload tree validation still runs. Bounded descriptor reads, payload size bounds during hashing and JSON nesting limits reduce resource exhaustion risks. Existing hash-only CLI remains clearly integrity-only; it does not imply publisher approval.

No release private keys handled, no network fetches, no install/execute actions. Tests use synthetic keypairs only. Signature validation establishes possession of the independently pinned signing key, not artifact-level Authenticode, host compatibility, dependency completeness, immutable staging, offline installation or official release approval. Caller must hold a trusted staging lock and ensure the exact verified bytes are later consumed. Production signer custody, signed release publishing, approved runtime/OS support, digest-pinned image and dependency set, private PKI, and physically disconnected install/upgrade/rollback remain required. DEC-001 open. Do not replace existing public-DNS deployment gates.
