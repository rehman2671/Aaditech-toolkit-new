# Windows LAN host reference observation (LAN-02)

Local Windows PowerShell 5.1/7 script observes OS product type, administrator token, logical CPU, physical memory, drive-root capacity, exact service name and active TCP listener snapshots. Explicit thresholds and local fixed-drive marker paths required; UNC/provider/device paths, reparse ancestors and malformed service names are not admitted. Only filesystem metadata is inspected; no credential contents, changes, network transfers, service start or installation. Result is redacted and always installation_authorized=false. Missing service or incomplete query is UNKNOWN; marker absence is not proof of no database or prior deployment. Drive-root space does not establish mounted-volume capacity, quota or directory write permissions. Listener snapshots are not port reservations. Host/runtime support, actual database/service discovery, safe concurrent locking, storage/ACL and Windows Server deployment acceptance remain pending. Native tests run on Windows CI in both shells; no physical Server support claim.
