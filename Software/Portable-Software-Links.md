# Portable Software — Direct Download Links

I can't bundle .exe files into this toolkit (they'd need to be verified and re-downloaded
per machine anyway), but here are the **official, safe sources** for every tool mentioned.
Download once, put the extracted files in `Software/`, and you'll never need to redownload.

| Tool | Purpose | Official Source |
|---|---|---|
| Sysinternals Suite (Process Explorer, Autoruns, TCPView, PsTools, RAMMap, etc.) | Bundle of 70+ Microsoft troubleshooting tools — covers most of the individual tools below | https://learn.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite |
| Microsoft PowerToys | Always On Top, PowerRename, Mouse Finder, Text Extractor, Color Picker, Screen Ruler | https://github.com/microsoft/PowerToys/releases |
| Notepad++ (portable) | Better text/log editor | https://notepad-plus-plus.org/downloads/ |
| WinDirStat | Visual disk space analyzer | https://windirstat.net/download.html |
| 7-Zip | Archive tool | https://www.7-zip.org/download.html |
| PuTTY (portable) | SSH/Telnet client | https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html |
| Advanced IP Scanner | Fast LAN device scanner | https://www.advanced-ip-scanner.com/ |
| CrystalDiskInfo | Disk SMART health monitor | https://crystalmark.info/en/software/crystaldiskinfo/ |
| HWiNFO | Detailed hardware diagnostics | https://www.hwinfo.com/download/ |
| CPU-Z | CPU/RAM/motherboard identification | https://www.cpuid.com/softwares/cpu-z.html |

## Notes
- Sysinternals Suite alone replaces Process Explorer, Autoruns, TCPView, PsTools, and several
  others individually listed above — download that first, it covers 80% of use cases.
- Always download directly from the vendor domain listed above, never from a third-party
  "download portal" — several of those bundle adware installers.
- Check your company's software policy before installing anything on managed/domain machines,
  even portable tools — some environments block execution from removable media by policy.
- Re-check version numbers every few months; these links point to the vendor's latest-version
  page, not a pinned file, so they'll always give you the current build.
