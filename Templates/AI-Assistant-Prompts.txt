IMPORTANT - SANITIZE FIRST:
Before pasting error codes, logs, or screenshots, REMOVE:
  • Hostnames and server names → replace with <HOSTNAME>
  • Real IP addresses → replace with <IP>
  • Usernames → replace with <USERNAME>
  • Domain names → replace with <DOMAIN>
  • Customer/company info → generalize
These are public AI tools. Your company policy matters.

SECTION 1: TROUBLESHOOTING & ERROR ANALYSIS
====================================================

--- PROMPT 1: Decode Windows Error Code ---
"I'm a desktop support engineer troubleshooting a Windows system. Explain this error 
in simple terms, most likely cause, and the fastest fix:
Error Code: [paste code, e.g., 0x80004005]
Error Message: [paste full error text]
Context: [where did it occur, what were you doing]"

--- PROMPT 2: Event Viewer Log Analysis ---
"I found this event log entry on a Windows machine. Explain if it's a real problem 
I need to fix or just an informational log I can ignore:
Event ID: [paste]
Source: [paste]
Full Log Text: [paste sanitized log]"

--- PROMPT 3: Blue Screen of Death (BSOD) Analysis ---
"Explain what caused this BSOD and the most reliable way to fix it:
Error: [e.g., DRIVER_IRQL_NOT_LESS_OR_EQUAL]
Context: [when it happens - startup, specific app, random?]
Recent changes: [any new software, drivers, Windows updates?]
(Also give me the fastest fix vs the thorough fix)"

--- PROMPT 4: Application Crash Troubleshooting ---
"This application keeps crashing with this error. Give me a step-by-step diagnostic plan 
ordered by likelihood/ease of fix:
Application: [name]
Error Message: [paste]
When it crashes: [startup / when opening a file / during a specific task]
Environment: [Windows 10/11 version, corporate domain or personal machine]"

--- PROMPT 5: Performance Issue Diagnosis ---
"A user reported their machine is running slowly. Walk me through the most efficient 
way to diagnose the cause (CPU, RAM, disk, network) and what to look for:
Symptoms: [laggy? freezes? specific app slow? all apps slow?]
Recent changes: [new software, Windows update, hardware change?]
What tools should I check in Task Manager?"

--- PROMPT 6: Network Connectivity Troubleshooting ---
"A user can't connect to [service/internet/server]. Walk me through the diagnostic 
steps from most likely/easiest to least likely/hardest:
Service they can't reach: [e.g., company VPN, website, internal server]

--- PROMPT 7: Printer Not Working ---
"Printer isn't working correctly. Help me troubleshoot in order of likelihood:
Symptom: [won't print at all / prints garbled / prints very slowly / offline]

--- PROMPT 8: Slow Network Speed ---

====================================================
TIPS FOR BEST RESULTS
====================================================

✓ Copy entire prompt INCLUDING the quotes, not just the content
✓ Always include your actual error messages (sanitized)
✓ Be specific about your environment (OS, version, domain/personal)
✓ Mention what you've already tried
✓ Ask follow-up questions if the first response isn't clear enough
✓ Never trust AI output blindly - verify before running on production
✓ AI is fastest at explanation, second-fastest at scripting, slowest at complex judgment

Remember: AI is a reference tool to speed you up, not a replacement for thinking.
Always understand what you're doing before you do it, especially on live systems.
